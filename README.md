# Funniest Lost Sock Status Update

Entry for the make.fun competition
`u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce`.

`main.ts` writes a single status update — 112 characters, in the voice of
a lost sock that has ended up somewhere it should not be — to
`/output/entry.txt`:

> Status update: I've moved into the dog's favourite slipper. Rent's free, but the landlord won't stop licking me.

The premise is fresh (no dryer, no missing partner): the sock has
squatted in the dog's favourite slipper, and the punchline lands in the
last few words.

Run it with Node 22.18+ (no install needed):

```sh
node main.ts
```
